# Call Forth

For artists and creators to push past the resistance and make the thing.

Pick what's in the way. Walk through it. Make the thing. A web app that gets creators from blocked to making in under two minutes. By Suzanne Mozes.

## What's here

| Path | What it is |
|---|---|
| `prototype/index.html` | The complete working prototype in one file. **The source of truth** for design, wording, layout, animation and behavior. Open it in a browser to try it. The dashed "Preview: jump to screen" panel is a testing tool, not part of the app. |
| `docs/App Brief.md` | The full written spec: every screen, rule, piece of content and tracked event. |
| `docs/AI Studio build prompts.md` | The five build phases, in order. |
| `docs/Phase 1 paste-in.txt` | The Phase 1 prompt plus the App Brief, for tools that only accept pasted text. |
| `components/` | Finished, tested React components to copy in as they are, starting with the breathing circle (`BreathCircle.tsx` and `koshi.ts`). |
| `screenshots/` | 14 key phone screens, numbered in the order a person moves through the app. |

## For AI builders

Rebuild `prototype/index.html` faithfully as a React app, phones first: same screens, words, colors, fonts, spacing, animations and logic. Do not redesign, rename, add or remove anything. Where the prototype and the brief differ, follow the prototype. Then follow the phases in `docs/AI Studio build prompts.md`: real sign-in and saving, the $27 studio upgrade, studio hours, then launch polish.
